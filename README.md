## Iniciar proyecto
1. Tener instalado y ejecutado Docker
2. Ingresar a la carpeta del proyecto e-commerce desde la consola
3. Ejecutar: docker-compose up -d --build
4. Ingresar al frontend en el navegador: http://localhost
5. Iniciar sesion con usuario ADMIN para ver todas funcionalidades:
    - Usuario: admin@admin.com
    - Clave: admin
